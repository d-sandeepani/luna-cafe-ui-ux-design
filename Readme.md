# Luna Café — Small Business UI/UX Design

## Overview

Luna Café is a fictional small-business café brand created as a UI/UX design portfolio project.

The project focuses on creating a consistent visual identity and responsive website experience across desktop and mobile devices.

## Project Goals

* Create a modern café website UI
* Build a consistent design system
* Design responsive desktop and mobile layouts
* Create a clickable website prototype
* Create supporting marketing materials
* Practice presenting a complete design project

## Tools Used

* Figma — UI/UX design, wireframing, design system and prototyping
* Adobe Photoshop — image editing and image preparation
* Canva — marketing and promotional graphics

## Website Pages

* Home
* About
* Menu
* Contact

## Design System

The design system includes:

* Brand colors
* Typography
* Buttons
* Cards
* Form fields
* Navigation
* Spacing
* Border radius
* Components

## Responsive Design

The website was designed for:

* Desktop — 1440px
* Mobile — 390px

The mobile layouts were redesigned for smaller screens rather than simply scaling down the desktop layouts.

## UX Flow

Main navigation:

Home → About
Home → Menu
Home → Contact

Primary calls to action:

View Menu → Menu
Visit Us → Contact

## Design Process

1. Brand concept
2. Wireframing
3. Design system
4. Desktop UI
5. Mobile UI
6. Component design
7. Prototyping
8. Image editing
9. Marketing design
10. Final presentation
